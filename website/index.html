Slash Commands

Type / to get started.

/ping

Check whether the bot is online and see the current API response latency.

/help

Get a private list of all available commands with descriptions. Only visible to you.

/say message

Make the bot send a message in the current channel.

Requires Manage Messages
/userinfo user?

Show account details for any server member — join date, top role, account age.

/serverinfo

Display stats for the current server: member count, channel count, creation date.

/alarm minutes message

Set a reminder. The bot will ping you in this channel after the specified number of minutes (1–1440).

/dice sides? count?

Roll one or more dice. Defaults to a single d6. Supports up to 10 dice with up to 100 sides each.

/funfact

Get a random fun fact picked from a curated list of 28.

/poll question option1 option2

Create a poll with 2–4 options. The bot posts the poll and adds number reactions automatically so members can vote.

/coinflip

Flip a coin and get heads or tails.

/joke

Get a random joke — setup and punchline delivered in an embed.

/quote

Get a random inspirational quote from a curated list.

/announce title message color?

Post a formatted announcement embed in the channel with a title, body, and optional accent color.

FAQ

Common questions.

How do I add the bot to my server?
Click Add to Discord, sign in if prompted, pick your server from the dropdown, and confirm the permissions. The bot will be online within seconds — no further setup needed.
Why does the bot need permissions?
Only the minimum are requested: Send Messages, Embed Links, and Read Message History. No administrator access is ever required.
How do I use a slash command?
Type / in any text channel where the bot is present. Discord will show an autocomplete menu — pick a command and fill in any options.
Can I limit the bot to specific channels?
Yes. Go to Server Settings → Integrations → MyBot and configure per-command channel and role restrictions from there.
